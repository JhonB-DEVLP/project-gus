# Design note

> Draft prepared during planning. Rewrite it in your own words before submitting.

## Direction

The site reads like the datasheet of a machine. Each project is a part with a number (PRJ-01), a spec table and a revision line. I build products where the details matter more than the decoration, and a spec sheet says that better than a hero image. The colour is British racing green: I like British design, and I ride a Triumph. Motorcycles are sold with spec sheets, so the two ideas meet.

## References

- **Electronic component datasheets.** Part numbers, spec tables, the revision line and figure captions (FIG. 1).
- **PP Neue Montreal (neuemontreal.com).** Giant type as the layout, letters rising into place, and the contrast between huge display type and small mono labels.
- **Emil Kowalski (emilkowal.ski).** Short motion with a purpose, used on hover, focus and state changes rather than everywhere.

## A decision I changed

I started with near-black and a signal orange. It worked, but it looked like many developer portfolios, and the orange sat close to the contrast limit in small mono labels. I moved to British racing green: it has a reason that is mine, and the accent reaches about 8:1 in both themes.

I also planned a type-only site with no images. The project pages felt like claims without proof, so I added figures with datasheet captions.
